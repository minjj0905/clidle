> 터미널에서 매일 한 단어씩, 한글 자모로 즐기는 워들류 게임

두벌식 로마자로 입력하면 화면에는 한글 자모가 뜹니다. 매일 자정(KST)에 바뀌는 오늘의 단어를 5~7번의 시도 안에 맞혀보세요. 같은 날엔 모두가 같은 문제를 풀기 때문에 결과를 공유하고 서로 비교하는 재미도 있습니다.

터미널만 있으면 바로 시작할 수 있어요 — 지금 설치해서 오늘의 문제를 풀어보세요!

---

## 실행 환경

- Node.js 18 이상
- macOS / Linux / WSL (Windows 기본 cmd/PowerShell 미지원)
- 한글 폰트를 지원하는 터미널 (iTerm2, Wezterm, Windows Terminal 등)
- 인터넷 연결 (오늘의 문제와 채점을 서버에서 받아옵니다)

---

## 설치 및 실행

```bash
git clone https://github.com/minjj0905/clidle.git
cd clidle
npm install
npm start
```

`npx clidle`로 바로 실행하는 배포는 준비 중입니다.

## 게임 방법

### 기본 규칙

- 오늘의 단어는 날짜 시드로 고정 → 같은 날 모든 유저가 동일한 단어
- 슬롯(칸) 수는 5~7칸으로 날짜마다 달라짐
- 시도 횟수: 5칸 → 6회 / 6칸 → 6회 / 7칸 → 7회
- 사전에 없는 자모 조합은 제출되지 않습니다 (서버가 실제 등재된 단어인지 검증)

### 입력 방식

한글 IME 대신 **두벌식 로마자 매핑**으로 입력합니다.

**자음**

| 키 | 자모 | 키 | 자모 | 키 | 자모 | 키 | 자모 |
|----|------|----|------|----|------|----|------|
| r | ㄱ | s | ㄴ | e | ㄷ | f | ㄹ |
| a | ㅁ | q | ㅂ | t | ㅅ | d | ㅇ |
| w | ㅈ | c | ㅊ | z | ㅋ | x | ㅌ |
| v | ㅍ | g | ㅎ | | | | |

**모음** — 전용 키가 있는 기본 모음 10개만 입력할 수 있습니다

| 키 | 자모 | 키 | 자모 | 키 | 자모 | 키 | 자모 |
|----|------|----|------|----|------|----|------|
| k | ㅏ | i | ㅑ | j | ㅓ | u | ㅕ |
| h | ㅗ | y | ㅛ | n | ㅜ | b | ㅠ |
| m | ㅡ | l | ㅣ | | | | |

**쌍자음** — 같은 자음 키를 두 번 입력하면 단자음 두 슬롯이 쌓입니다 (예: `rr` → `ㄱ`, `ㄱ`)

| 입력 | 결과 | 입력 | 결과 |
|------|------|------|------|
| rr | ㄱ, ㄱ | ee | ㄷ, ㄷ |
| qq | ㅂ, ㅂ | tt | ㅅ, ㅅ |
| ww | ㅈ, ㅈ | | |

**겹모음** — 전용 키가 없는 나머지 모음도 기본 모음 조합으로 입력합니다

| 겹모음 | 입력 | 겹모음 | 입력 |
|--------|------|--------|------|
| ㅐ | `ㅏ`+`ㅣ` | ㅒ | `ㅑ`+`ㅣ` |
| ㅔ | `ㅓ`+`ㅣ` | ㅖ | `ㅕ`+`ㅣ` |
| ㅘ | `ㅗ`+`ㅏ` | ㅙ | `ㅗ`+`ㅏ`+`ㅣ` |
| ㅚ | `ㅗ`+`ㅣ` | ㅝ | `ㅜ`+`ㅓ` |
| ㅞ | `ㅜ`+`ㅓ`+`ㅣ` | ㅟ | `ㅜ`+`ㅣ` |
| ㅢ | `ㅡ`+`ㅣ` | | |

### 힌트

시도한 칸마다, 그리고 지금까지 입력한 자음/모음을 모아 보여주는 가상 키보드에 아래 4가지 색으로 현황이 표시됩니다.

| 색상 | 의미 |
|------|------|
| 🟦 청록 (bold) | 위치와 자모 모두 정확 |
| 🟪 자홍 (bold) | 자모는 있으나 위치는 틀림 |
| ⬜ 회색 | 단어에 해당 자모가 아예 없음 |
| 흰색(기본) | 아직 입력하지 않은 자모 (가상 키보드 전용) |

### 통계 & 결과 공유

- 게임 종료 시 전체 도전 수, 정답률, 현재/최다 연속 정답, 시도 횟수별 분포를 보여줍니다. 정답 단어 자체는 화면에 표시되지 않습니다.
- `c` 키를 누르면 아래와 같은 형식의 결과가 클립보드에 복사됩니다.

```
CLIDLE 20260716 3/6

🟪🟦⬜⬜⬜
⬜🟪⬜🟪⬜
🟦🟦🟦🟦🟦
```

- 진행 상황은 `~/.clidle/state.json`에, 통계는 `~/.clidle/stats.json`에, 익명 기기 식별자는 `~/.clidle/device.json`에 저장됩니다.

## 프로젝트 구조

```
clidle/
├── src/                     # CLI 클라이언트
│   ├── index.tsx            # 진입점 (백엔드에서 오늘의 문제를 받아 렌더링)
│   ├── App.tsx               # 루트 컴포넌트, 키 입력 처리
│   ├── game.ts                # 게임 상태 관리 (채점은 서버에 위임)
│   ├── input.ts                 # 두벌식 로마자 → 자모 입력기
│   ├── hint.ts                   # 힌트 계산 (로컬/테스트용)
│   ├── keyboard.ts                # 가상 키보드 자모별 상태 집계
│   ├── seed.ts                     # 날짜 시드 계산
│   ├── api.ts                       # 백엔드 API 클라이언트
│   ├── storage.ts                    # 진행 상황/통계/기기 식별자 저장 (~/.clidle/)
│   ├── stats.ts                       # 누적 통계 계산
│   ├── share.ts                        # 결과 공유 텍스트 생성 / 클립보드 복사
│   ├── types.ts                         # 공용 타입 정의
│   └── render/                          # ink 렌더링 컴포넌트
│       ├── title.tsx, board.tsx, keyboard.tsx, legend.tsx, result.tsx
├── backend/                 # Vercel(Next.js) API + 관리자 백오피스 — 자세한 내용은 backend/README.md
├── scripts/                 # 단어 DB 전처리/이관 스크립트
├── supabase/schema.sql      # DB 스키마
├── test/                    # vitest 테스트
└── package.json
```

## 단어 출처

- 국립국어원 한국어기초사전 (TOPIK 수험용 학습 어휘)
- 한국교육학술정보원 모두의한국어 단어장

학습 어휘 출처의 단어는 오늘의 정답 후보로도 쓰이고, mecab-ko-dic에서 확충한 단어는 입력(제출)은 가능하지만 너무 희귀해 정답 후보에서는 제외됩니다.

```bash

```


### PR 전 체크리스트

- `npm run typecheck`, `npm test` 통과 (`backend/` 변경 시 `backend`에서도 `npx tsc --noEmit`)
- 커밋 메시지 형식: `<type>: <subject>` (`feat`/`fix`/`refactor`/`chore`/`docs`), 제목은 50자 이내로 간결하게
- 게임 규칙(입력/힌트 계산/단어 DB)을 바꿨다면 관련 테스트도 함께 갱신
