> 터미널에서 실행하는 한글 자모 단어 맞히기 게임

두벌식 로마자 입력으로 한글 자모를 맞히는 CLI 단어 게임입니다.  
매일 날짜 시드로 고정된 오늘의 단어를 자모 단위로 추측하세요.

---

## 실행 환경

- Node.js 18 이상
- macOS / Linux / WSL (Windows 기본 cmd/PowerShell 미지원)
- 한글 폰트를 지원하는 터미널 (iTerm2, Wezterm, Windows Terminal 등)

---

## 설치 및 실행

```bash
# npx로 바로 실행 (배포 후)
npx clidle

# 또는 로컬 클론 후 실행
git clone https://github.com/minjj0905/clidle.git
cd clidle
npm install
npm start
```

---

## 게임 방법

### 기본 규칙

- 오늘의 단어는 날짜 시드로 고정 → 같은 날 모든 유저가 동일한 단어
- 슬롯(칸) 수는 5~7칸으로 날짜마다 달라짐
- 시도 횟수: 5칸 → 6회 / 6칸 → 6회 / 7칸 → 7회

### 입력 방식

한글 IME 대신 **두벌식 로마자 매핑**으로 입력합니다.

**자음**

| 키 | 자모 | 키 | 자모 | 키 | 자모 | 키 | 자모 |
|----|------|----|------|----|------|----|------|
| r | ㄱ | s | ㄴ | e | ㄷ | f | ㄹ |
| a | ㅁ | q | ㅂ | t | ㅅ | d | ㅇ |
| w | ㅈ | c | ㅊ | z | ㅋ | x | ㅌ |
| v | ㅍ | g | ㅎ | | | | |

**모음**

| 키 | 자모 | 키 | 자모 | 키 | 자모 | 키 | 자모 |
|----|------|----|------|----|------|----|------|
| k | ㅏ | o | ㅐ | i | ㅑ | j | ㅓ |
| p | ㅔ | u | ㅕ | h | ㅗ | y | ㅛ |
| n | ㅜ | b | ㅠ | m | ㅡ | l | ㅣ |

**쌍자음** — 같은 자음 키를 두 번 입력

| 입력 | 결과 | 입력 | 결과 |
|------|------|------|------|
| rr | ㄲ | ee | ㄸ |
| qq | ㅃ | tt | ㅆ |
| ww | ㅉ | | |

### 힌트

| 색상 | 의미 |
|------|------|
| 🟩 초록 계열 | 위치와 자모 모두 정확 |
| 🟨 노랑 계열 | 자모는 있으나 위치 틀림 |
| ⬛ 어두운 계열 | 해당 자모 없음 |

## 프로젝트 구조

```
clidle/
├── src/
│   ├── index.js          # 진입점
│   ├── game.js           # 게임 상태 관리

│   └── data/

│       ├── words_6.json

├── scripts/
│   └── preprocess.js     # 단어 DB 전처리 스크립트
```
